# Changelog

## 1.1.0 — The Liquid Glass Update · 2026-11-01

### Changed

- Added pronounced liquid-glass presentation in both light and dark themes across the HomeBase interface.
- Added a fixed blue/violet/cyan backdrop, reflective pane edges and floating rounded navigation.
- Preserved readable form surfaces, reduced-transparency/high-contrast fallbacks, reduced-motion behavior and lighter phone blur.
- Rounded the Devices filter rail and kept its narrow-layout wrapping.
- Updated the release documentation and UI previews.

### Included from updates after the original 1.0.0 bundles

- Full-screen local sign-in and clearer first-account instructions.
- Verified two-factor removal with all-session revocation.
- Dedicated Smart TVs navigation, expanded capability-aware remotes and digital keyboard.
- Secure LG webOS pairing with approved certificate identity pinning.
- Provider-logo and local-address navigation improvements.

No new Samsung pairing fix or additional hardware compatibility is claimed. Account storage and setup remain compatible with the earlier source. See [release notes](docs/RELEASE-NOTES-1.1.0.md) for installation, upgrade and validation details.

## 1.0.0 — Initial source previews

Local-first Docker/Raspberry Pi command centre, supported network discovery and integrations, protected local account/vault, device-action approvals and installation documentation. The original `v1.0.0` and `v1.0.0-telstra-fix` tags remain preserved as historical previews.

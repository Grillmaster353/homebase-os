# Brand artwork sources

Logos identify devices and providers in the local dashboard. They do not imply affiliation or endorsement. Transparent vector artwork is bundled locally; displaying a badge does not contact a logo service. Unknown brands use the generic router icon and their real reported name.

## Simple Icons

The assets listed below use the SVG paths from [Simple Icons](https://github.com/simple-icons/simple-icons), revision `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`. The project supplies these vectors under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/LICENSE.md); trademark rights remain with their owners. Original brand colors and optional light monochrome variants use the same source geometry.

Cloudflare (`cloudflare-inc`) uses the [Simple Icons vector](https://raw.githubusercontent.com/simple-icons/simple-icons/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/icons/cloudflare.svg) under CC0-1.0; brand source: [Cloudflare](https://www.cloudflare.com/). It identifies an internet exit network, which may be a VPN rather than the retail ISP.

SVG view boxes are fitted to their visible vector bounds for readable small badges. Source path geometry is unchanged; no background was added.

Exetel (`exetel`) is the official inline SVG in the homepage header link labelled “Exetel homepage”, retrieved from [Exetel](https://www.exetel.com.au/). Styling-only classes were removed and a light variant uses the same paths. No background was added. Exetel retains its trademark rights; this local asset identifies the selected or detected provider and implies no endorsement.

Broadband Solutions (`broadband-solutions`) uses its [official transparent header SVG](https://managedit.broadbandsolutions.com.au/wp-content/uploads/2021/09/logo-01.svg) from the provider's [Managed IT website](https://managedit.broadbandsolutions.com.au/). The original vector and a light monochrome variant retain the same geometry, with no added background. Broadband Solutions retains its artwork and trademark rights; this badge identifies the provider, not a router manufacturer.

Telstra (`telstra`) uses the [official transparent website header SVG](https://www.telstra.com.au/etc/designs/lego/nav-lego/assets/t-logo.svg) from [Telstra](https://www.telstra.com.au/). The original coral/blue artwork is used on the dark dashboard; a light monochrome variant retains the same paths. No background was added. Telstra retains its artwork and trademark rights. The badge identifies the detected or selected provider, including BigPond aliases, without implying affiliation or endorsement.

Optus uses the transparent wordmark from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Optus_logo.svg), with an identical light path variant for dark mode. The wordmark remains an Optus trademark. Vocus uses its [official header vector](https://www.vocus.com.au/globalassets/global-media/brand/logos/vocus-header-logo.svg) and [official white variant](https://www.vocus.com.au/globalassets/global-media/brand/logos/logo---vocus-white-rgb.svg). Flip uses its official transparent [white](https://flipconnect.com.au/storage/website/v1/flip-logo-white.webp) and [red](https://flipconnect.com.au/storage/website/v1/flip-logo-red.webp) header logos (the white asset is served as PNG by the provider) from [Flip](https://flipconnect.com.au/). These identify the selected or detected provider; Telstra/Optus router marks are used only for an explicit router brand, never inferred from the ISP. All artwork is served locally, without contacting a logo service.
